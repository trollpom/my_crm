My-CRM — локальный планировщик с ИИ-помощником

Актуальная документация: README.md
Предыдущий CLI-планировщик: README_PM.txt

forward_mail.py и forward_mail_loop.py — отдельные прежние утилиты пересылки почты. Они отправляют реальные письма/уведомления в настроенный Telegram и не нужны для демонстрации веб-приложения. Запускайте их только после проверки конфигурации и получателей.
