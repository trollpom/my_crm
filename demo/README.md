# my_crm: безопасная локальная демонстрация

Демонстрация запускает исходный интерфейс и API на `127.0.0.1:8777` с новой временной базой: 3 вымышленных проекта и 8 задач. Почтовые ящики пусты; ИИ отключён и ключ пуст. Ответы модели не имитируются.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install fastapi uvicorn requests pypdf
python demo/run_demo.py
```

Откройте http://127.0.0.1:8777/ . При занятом порте: `python demo/run_demo.py --port 8780`.

## Сценарий на 60 секунд

1. «Обзор»: проекты, приоритеты и сроки синтетических задач.
2. «Канбан-доска»: откройте карточку, измените прогресс или статус и сохраните.
3. «Графики и Гантт»: покажите задачи во времени.
4. «ИИ-помощник»: поясните рабочую интеграцию DeepSeek и то, что в этой демонстрации она отключена.

Скрипт копирует только каталог `app/` в новую временную папку, создаёт собственные `config.json` и `notion.db`. Рабочие настройки, база, переписка, вложения и папки проектов из исходного checkout не копируются. Каждый запуск создаёт новую базу; после штатного выхода временная папка удаляется. После аварийного завершения её может потребоваться удалить вручную.

Завершение — Ctrl+C. Не добавляйте реальную почту, ключи или персональные данные в демосеанс. Приложение рассчитано на один локальный процесс; это не публичный сервер с авторизацией. Для публичной интерактивной версии нужны отдельные согласованные изменения доступа и изоляции пользователей.

## Автоматическая проверка запуска

```bash
python demo/smoke_test.py
```

Проверяет реальный старт временного сервера, HTTP 200 интерфейса, 8 синтетических задач, нулевые счётчики почты и отключённый ИИ без ключа. Рабочая база и настройки не используются.
