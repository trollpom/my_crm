# Обезличенная версия для портфолио

Этот репозиторий создаётся как самостоятельный проект с одним начальным коммитом. Предыдущие ветки, теги, коммиты, рабочие конфигурации и архивы в него не переносятся.

В набор входят исходники приложения, инструкции, изолированный демозапуск, smoke-тест и реальные изображения интерфейса на синтетических данных. Демонстрационные три проекта, восемь задач и заметка вымышлены. Настоящая переписка и ключи для показа не нужны.

В `config.example.json` список почтовых ящиков пуст, ИИ отключён, ключ пуст. Собственные почтовые и AI-интеграции остаются в коде и требуют явной локальной настройки. Их доставка, доступность провайдера и качество ответов этой демонстрацией не подтверждаются.

Проверка: `python demo/smoke_test.py` запускает временный сервер и проверяет HTTP 200, восемь задач, нулевые счётчики почты и отключённый ИИ без ключа. Это smoke-тест, а не полный аудит приложения.

Отдельная публикация не удаляет данные из других репозиториев или ранее сделанных сторонних копий.
