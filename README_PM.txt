# Предыдущий CLI-планировщик на базе почты

Система читает вашу рабочую почту по IMAP, копит задачи/проекты с дедлайнами,
шлёт напоминания в Telegram, делает ежедневный план и календарь .ics.

## Файлы

- `config.json` — настройки (Telegram, IMAP, расписание)
- `tasks.json` — база ваших задач и проектов (все дела хранятся здесь)
- `pm.py` — командная строка (добавить/выполнить/план и т.д.)
- `pm_loop.py` — фоновый процесс (проверка почты + напоминания + утренний план)
- `pm_core.py` — ядро (задачи, даты, Telegram)
- `pm_mail.py` — работа с почтой (IMAP, поиск сроков в письмах)
- `calendar.ics` — календарь для Outlook/Thunderbird (каждая задача = событие)
- `mail_cache/` — кэш писем (тексты для анализа)
- `state.json`, `last_email.json` — служебные файлы прогресса

## Первая настройка

1. Заполнить `config.json`:
   - `telegram_bot_token` и `telegram_chat_id` (как получить — ниже)
   - `email` и `password` — ваш собственный тестовый почтовый ящик
2. Проверить, что компьютер видит сервер: `imap.example.invalid:993`
3. Установить зависимости: `pip install requests`
4. Загрузить историю писем: `python pm.py fetch`
5. Посмотреть, где в письмах есть сроки: `python pm.py scan --verbose`

## Команды

```
python pm.py add "Сдать отчёт" -d "25.09.2026 18:00" -p "Бухгалтерия" --priority high --send
python pm.py add "Позвонить клиенту" -d "завтра 10:30"
python pm.py add "Встреча" -d "пятница 14:00"
python pm.py add "Созвон" -d "через 2 дня 15:00"
python pm.py list                # все открытые задачи по дедлайнам
python pm.py done 3              # задача выполнена
python pm.py cancel 3            # отменить
python pm.py edit 3 -d "01.10.2026 12:00"   # перенести дедлайн
python pm.py today               # ежедневный план (в консоль)
python pm.py today --send        # план в Telegram
python pm.py remind              # отправить напоминания по подходящим дедлайнам
python pm.py fetch               # загрузить новые письма
python pm.py scan                # найти упоминания сроков в письмах
python pm.py ics                 # пересоздать calendar.ics
```

Форматы дат: `25.09.2026`, `25.09`, `25 сентября`, `сегодня`, `завтра`,
`послезавтра`, `понедельник`…`воскресенье`, `через N дней/часов/недель`,
можно с временем `15:30`.

## Как получить Telegram-токен и chat_id

- Токен: в Telegram найдите `@BotFather`, команда `/newbot`, скопируйте выданный токен.
- Chat ID: напишите `@userinfobot` команду `/start` — пришлёт число.

## Фоновый режим

```
python pm_loop.py
```

Что делает каждые `check_interval_seconds` секунд:
1. Загружает новые письма с сервера.
2. Отправляет напоминания, если до дедлайна осталось меньше
   `remind_minutes_before_deadline` минут (по одному разу на задачу).
3. В `digest_time` (по умолчанию 09:00) отправляет в Telegram утренний план:
   просроченное, сегодня, ближайшие 3 дня, свежие письма.

Автозапуск в Windows: `Win+R` → `shell:startup` → создать `mail_pm.bat`:
```
@echo off
cd /d "путь\Планировщик работы"
python pm_loop.py
```

## Примечание

Это документация предыдущего CLI-режима. Для текущего веб-приложения используйте README.md. Команды с --send отправляют сообщения в настроенный Telegram; перед запуском проверьте получателя.
