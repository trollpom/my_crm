# Безопасность и демонстрация

Приложение предназначено для одного пользователя на `127.0.0.1`, без публичной серверной авторизации.

- Публичный набор содержит код и синтетические примеры, без рабочих конфигураций, писем, баз и журналов.
- Для просмотра используйте `python demo/run_demo.py`: отдельная временная база, пустая почта и отключённый ИИ.
- `config.json`, `.env`, почтовые пароли, API-ключи, SQLite-базы, вложения и журналы не должны попадать в Git.
- Рабочие интеграции настраиваются только локально и явно. Для почты требуется корректный TLS-сертификат сервера.
- Перед отправкой контекста в LLM убедитесь, что данные допустимо передавать выбранному провайдеру.
- Приложение хранит локальные секреты в JSON без собственного шифрования. Ограничьте доступ к компьютеру и файлам.

Если опубликован настоящий ключ или пароль, отзовите его у провайдера. Удаление файла не отзывает секрет и не очищает чужие копии.
